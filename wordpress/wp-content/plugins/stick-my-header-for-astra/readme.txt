Improve your website's header design and make it stick to the top once **Stick My Header For Astra** is activated. 

== Description ==

The Stick My Header for Astra plugin allows you to **make your website's header section sticky**. This plugin is only used in Astra themes, it can't work if you use any other theme in your WordPress website.

It is so easy to use, with a set of design parameters that you can change, so **you can customize your header** design as you wish.

= Features =

* **Sticky Header**: after installing and activating this plugin, your website's header section will become sticky automatically.
* **Sticky Header on Mobile/Tablette**: you can activate/deactivate sticky header for small screens just by checking/unchecking a checkbox in the **MOBILE/TABLETTE** setting section in the WP customizer. 
* **Header Design Editing**: there is a set of design parameters that you can change in order to update your header look, like **Background Color, Opacity, Z-index, Header Shadow**...etc. 
* **Sticky Header Design Editing**: you have the possibility to change your website header design when it is sticky, by changing design parameters (almost the same as the Header Settings parameters above). 
* **Menu Design Editing**: improve Menu look. Menu can be the main navigation menu, sub menu or secondary navigation menu.  
* **CSS Code Adding**: you are able to write CSS code using this plugin, so you can update your website's look and design.

== Installation ==

1- Upload the "str-sticky-header" directory to your "wp-content/plugins" directory.
2- Login to your Website Administration interface.
3- In your WordPress admin, go to PLUGINS and activate "Stick My Header for Astra".
4- Click on "Stick My Header for Astra" icon in the left side admin bar.
5- Click on "Start Header Customizing" blue button.
6- Enjoy it !
